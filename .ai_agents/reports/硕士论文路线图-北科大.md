# openBIMForge: Nexus 协同编排硕士论文路线图 (北科大)

## 1. 核心愿景
通过多智能体、多模态编排框架，消除人类建筑意图与专业 BIM 构造之间的鸿沟。本路线图旨在指导 **北京科技大学（USTB）硕士学位论文** 的研究，并同步构建高质量的 **GitHub 简历项目**。

## 2. 第一阶段：多模态基座与自适应路由 (当前重点)
- [ ] **语音转 BIM 集成**：将 ASR（语音转文字）实现为前端输入通道。
- [ ] **自适应视觉路由 (Adaptive Vision Routing)**：
    - 使用多模态大模型（Gemini/GPT-4o）实现“视觉路由智能体”。
    - **路径 A（建筑逻辑提取）**：平面图 OCR -> 语义参数提取 -> Text-to-BIM。
    - **路径 B（形态生成）**：概念草图 -> GenCAD 扩散引擎 -> 3D 拓扑 (STL)。
- [ ] **原型系统稳固**：完成与 Vectorworks 2024 的端到端全链路闭环。

## 3. 第二阶段：智能体自纠错与闭环重构 (论文创新点/核心)
- [ ] **验证智能体 (Verifier Agent) 开发**：专门监控 Vectorworks VM 运行状态的智能体。
- [ ] **自我反思回路 (Self-Reflection Loop)**：
    - 捕获 Vectorworks 的 Python 错误堆栈或几何冲突。
    - 将错误日志反馈给 `Architect-Agent` 进行迭代逻辑修正。
- [ ] **学术贡献**：提出一种“闭环生成式 BIM 框架”，旨在消除工程任务中 LLM 的幻觉。

## 4. 第三阶段：领域特定智能 (学术深度提升)
- [ ] **BIM-API 指令微调**：针对 VectorScript/Python API 文档和常见 BIM 代码片段，微调轻量化模型（如 Llama-3-8B）。
- [ ] **RAG 增强**：构建针对建筑规范和标准 BIM 对象属性的向量数据库。
- [ ] **对比研究**：将微调后的模型与通用大模型进行基准测试，展示科研价值。

## 5. 第四阶段：评估、文档与开源发布
- [ ] **量化指标设定**：
    - **代码生成成功率**：脚本一次性运行通过的比例。
    - **几何保真度**：生成的房间面积与输入草图的误差。
    - **可用性评估**：相比手动建模节省的工时。
- [ ] **GitHub S 级展示**：
    - 高质量架构图 (Mermaid/Draw.io)。
    - 专业的全流程演示视频。
    - “点击即演示”模式：为没有 Vectorworks 的用户提供模拟生成效果。

## 📅 时间进度预估 (北科大硕士 track)
- **第 1-2 个月**：完成第一阶段开发与开题报告撰写。
- **第 3-4 个月**：实现第二阶段（自纠错）并收集实验数据。
- **第 5 个月**：执行第三阶段（微调）并优化 UI。
- **第 6 个月**：撰写论文定稿并完善 GitHub 仓库。
